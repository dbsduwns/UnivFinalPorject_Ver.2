# KNU Campus Life 기술명세서

## 1. 시스템 개요

KNU Campus Life는 강남대학교 학생을 위한 통합 캠퍼스 앱이다. 백엔드는 FastAPI 기반 REST API로 인증, 공지사항, 식단, 셔틀 시간표, 강의/과목, 시간표, 개인 일정, 챗봇 기능을 제공한다. 프론트엔드는 React Native Expo 기반 모바일 앱으로 구성하며, 현재는 인증 흐름과 기본 탭 구조를 중심으로 개발 중이다.

## 4. 주요 구현 구조

### 4.1 인증 및 권한

- 일반 이메일/비밀번호 회원가입과 로그인을 제공한다.
- 로그인 성공 시 access token과 refresh token을 발급한다.
- `/auth/me`는 현재 사용자 정보와 `is_admin` 값을 반환한다.
- 관리자 전용 API는 `get_current_admin_user` dependency로 보호한다.
- Google ID Token 로그인 엔드포인트가 추가되어 있으며, 실제 운영 전 검증과 보완이 필요하다.

### 4.2 공지사항

- 기존 공지 크롤러와 개선된 `notice_crawler_v2`가 존재한다.
- 개선된 크롤러는 카테고리별 공지 목록을 탐색하고, 이미 저장된 제목은 상세 수집을 생략한다.
- 새 공지는 DB 저장 후 RAG 문서로 ChromaDB에 인덱싱한다.
- 공지 조회 API는 카테고리와 제목 키워드 필터를 지원한다.
- **프론트엔드 최적화**: 
    - `React.memo`와 `useCallback`을 사용하여 목록 항목(`NoticeItem`)과 카테고리 선택기(`CategorySelector`)의 불필요한 리렌더링을 방지한다.
    - `categoryBadgeStyles`를 통해 카테고리별 고유 배경색과 글자색을 동적으로 적용한다.
    - 배지 너비를 고정하여 리스트의 시각적 일관성을 유지한다.

### 4.3 식단

- 강남대학교 식단 게시판의 주간 식단표 이미지를 크롤링한다.
- 제목의 날짜 범위를 파싱해 `daily_menus`에 날짜별 이미지 URL을 저장한다.
- 사용자는 날짜 기준으로 식단 이미지를 조회한다.

### 4.4 강의/과목

- 종합정보시스템 개설강좌 HTML을 파싱한다.
- HTML 문자열, HTML 파일 업로드, 학과별 크롤링 import를 지원한다.
- 과목은 `subjects`, 분반은 `courses`, 강의 시간은 `course_schedules`에 저장한다.
- 강의 목록 조회는 과목명, 학과, 교수명, 학기, 요일, 학점, 학수번호 필터를 지원한다.
- 교시-시간 매핑은 `PERIOD_TIME_MAP` 기반이며, 공식 교시표 확인 후 보정 가능하다.

### 4.5 시간표

- 사용자는 여러 시간표를 생성할 수 있다.
- 시간표 상세는 강의 목록, 개인 일정 목록, 총 학점을 포함한다.
- 강의 추가와 개인 일정 추가/수정 시 시간 충돌을 검사한다.
- 대표 시간표는 `is_main`으로 관리한다. 대표 시간표가 없을 수 있으며, 프론트에서는 없을 경우 최신 시간표를 기본으로 사용할 수 있다.

### 4.6 셔틀 시간표

- 강남대학교 무료셔틀 안내 페이지에서 다운로드 링크를 추출한다.
- `Content-Disposition` 헤더의 파일명에서 원본 파일명과 학기 정보를 추출한다.
- 최신 시간표만 활성화하기 위해 `is_active` 값을 사용한다.
- 저장된 셔틀 시간표 정보는 RAG 문서로도 인덱싱한다.

### 4.7 RAG 챗봇

- HuggingFace 한국어 임베딩 모델과 ChromaDB를 사용한다.
- Gemini 모델명은 `gemini-flash-latest`를 사용한다.
- 공지사항, 셔틀 시간표, **학사일정, 학교 규정** 문서를 벡터 DB에 추가하여 응답 품질을 높였다.
- 사용자의 질문은 검색된 컨텍스트와 함께 Gemini에 전달된다.

### 4.8 Scheduler

- 서버 시작 시 AI 봇을 초기화한다.
- 서버 시작 직후 학식(즉시), 셔틀(1분 후), 공지사항(2분 후) 크롤링을 **순차적으로 실행**하여 리소스 충돌을 방지한다.
- 주기 작업:
  - 공지사항: 1시간마다
  - 학식: 매일 새벽 1시
  - 셔틀: 12시간마다

### 4.9 Frontend

- Expo Router 기반 앱 구조가 생성되어 있다.
- 인증 화면, 로그인/회원가입 화면, Google 로그인 버튼, 기본 탭 화면이 존재한다.
- `AppDrawer`와 `QuickMenu`를 통해 하단 탭에 없는 기능(셔틀, 학식, 캠퍼스 맵 등)에 접근할 수 있다.
- **레이아웃 최적화**: `FlatList`와 같은 `VirtualizedList`를 사용할 때 부모 컴포넌트의 중첩 `ScrollView`를 제거하여 스크롤 성능 저하와 경고를 방지한다.
- Axios API 클라이언트는 access token을 자동 첨부하고, 401 응답 시 토큰 삭제 및 로그인 화면 이동을 수행한다.
- Zustand 기반 auth store와 SecureStore 기반 토큰 저장소가 구현되어 있다.

## 8. 실행 및 의존성

### 8.1 Backend

```bash
cd backend
pip install -r requirements.txt
playwright install chromium
alembic upgrade head
uvicorn app.main:app --reload
```

### 8.2 Frontend

```bash
cd frontend/knu
npm install
npm run start
```

프론트엔드 API 주소는 `EXPO_PUBLIC_API_URL`로 설정한다. 값이 없으면 기본값은 `http://127.0.0.1:8000`이다.
