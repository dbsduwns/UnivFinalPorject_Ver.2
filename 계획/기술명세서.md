# KNU Campus Life 기술명세서

## 1. 시스템 개요

KNU Campus Life는 강남대학교 학생을 위한 통합 앱 백엔드이다. 인증, 공지사항, 식단 이미지, 강의/과목 데이터, 시간표, 개인 일정, 챗봇 기능을 FastAPI 기반 REST API로 제공한다.

## 2. 기술 스택

### 2.1 Backend

- Python 3.13
- FastAPI
- Uvicorn
- Pydantic v2
- SQLAlchemy
- Alembic
- PostgreSQL
- python-jose 기반 JWT
- passlib/bcrypt 기반 비밀번호 해싱
- python-dotenv
- Playwright
- BeautifulSoup4
- APScheduler

### 2.2 Database

- PostgreSQL 15
- 주요 테이블:
  - `users`
  - `notices`
  - `daily_menus`
  - `subjects`
  - `courses`
  - `course_schedules`
  - `timetables`
  - `timetable_courses`
  - `custom_schedules`
  - `chat_rooms`
  - `messages`
  - `buildings`
  - `rooms`

## 4. 크롤링 및 Import 구조

### 4.1 공지사항

- Playwright로 강남대학교 홈페이지 공지사항 목록과 상세를 크롤링한다.
- 중복 방지를 위해 제목 기준으로 기존 공지를 확인한다.

### 4.2 식단

- SSO 로그인 후 식단 게시판의 이미지 공지를 크롤링한다.
- 제목의 날짜 범위를 파싱해 `daily_menus`에 날짜별 `image_url`을 저장한다.

### 4.3 강의/과목

- 종합정보시스템의 개설강좌 리스트 HTML을 파싱한다.
- `table.grid_list`의 각 행에서 학수번호, 분반, 과목명, 교수명, 학점, 시수, 강의시간을 추출한다.
- 과목은 `subjects`, 분반은 `courses`, 강의시간은 `course_schedules`에 저장한다.
- 강의시간 예: `(주)수1ab2ab3ab` -> `WED 09:00~11:50`
- 현재 교시 시간은 임시 매핑이며, 공식 교시표 확인 후 `PERIOD_TIME_MAP`을 보정할 수 있다.

## 5. 검증 완료 항목

- 서버 및 DB health check
- 회원가입, 로그인, JWT 인증
- `/auth/me` 현재 사용자 조회
- 공지사항 크롤링, 목록/상세/검색 조회
- 식단 이미지 크롤링, 날짜별 조회
- 강의 HTML 파일 업로드 import
- 강의 목록/상세 조회
- 시간표 생성/목록/상세 조회
- 시간표 상세에서 강의, 개인 일정, 총 학점 반환
- 시간표에 실제 강의 추가
- 개인 일정 생성/조회/삭제
- 챗봇 데모 응답, 채팅방 생성, 메시지 저장/조회
- 인증 누락 시 401 응답
- 존재하지 않는 리소스 요청 시 404 응답

## 6. 남은 고도화 과제

- 강의 시간 충돌 검사
- 개인 일정 시간 충돌 검사
- 시간표 이름/학기 수정 API
- 시간표 삭제 API
- 대표 시간표 변경 API
- custom schedule 수정 API
- 강의 검색 필터 확장: 학과, 학기, 교수명, 요일
- OpenAI 또는 RAG 기반 실제 챗봇 provider 연동
- 크롤러/관리자용 API에 관리자 인증 적용
- 운영 환경에서는 `create_all` 대신 Alembic migration 중심으로 전환
