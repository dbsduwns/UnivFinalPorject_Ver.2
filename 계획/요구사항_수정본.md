# KNU Campus Life 요구사항 수정본

## 1. 프로젝트 개요

강남대학교 학생을 위한 통합 앱으로, 공지사항, 식단 이미지, 개인 시간표, 강의 일정, 개인 일정, 인증 기반 사용자 기능을 하나의 서비스에서 제공한다.

## 2. 기능 요구사항

### 2.1 사용자 인증

- 사용자는 이메일, 비밀번호, 이름으로 회원가입할 수 있다.
- 사용자는 이메일/비밀번호로 로그인할 수 있다.
- 로그인 성공 시 access token과 refresh token을 발급한다.
- 사용자는 access token으로 내 정보를 조회할 수 있다.

### 2.2 공지사항

- 시스템은 강남대학교 공지사항을 크롤링해 DB에 저장할 수 있다.
- 사용자는 공지사항 목록을 조회할 수 있다.
- 사용자는 공지사항을 키워드로 검색할 수 있다.
- 사용자는 공지사항 상세 정보를 조회할 수 있다.
- 존재하지 않는 공지사항 요청은 404로 응답한다.

### 2.3 식단

- 시스템은 주간 식단표 이미지 공지를 크롤링할 수 있다.
- 식단표 제목의 날짜 범위를 분석해 각 날짜별 식단 이미지 데이터를 저장한다.
- 사용자는 날짜를 기준으로 식단 이미지를 조회할 수 있다.
- 식단이 없는 날짜는 빈 배열로 응답한다.

### 2.4 시간표

- 사용자는 본인 계정에 연결된 시간표를 생성할 수 있다.
- 사용자는 본인의 시간표 목록을 조회할 수 있다.
- 사용자는 본인의 특정 시간표를 조회할 수 있다.
- 사용자는 시간표에 강의를 추가하거나 삭제할 수 있다.
- 사용자는 시간표에 개인 일정을 추가, 조회, 삭제할 수 있다.
- 인증되지 않은 시간표 요청은 401로 응답한다.
- 본인 소유가 아니거나 존재하지 않는 시간표 요청은 404로 응답한다.

## 3. 비기능 요구사항

- API는 FastAPI Swagger 문서에서 테스트 가능해야 한다.
- DB 접근은 SQLAlchemy 세션을 통해 처리한다.
- 비밀번호는 해시로 저장한다.
- JWT 검증 실패 시 401 응답을 반환한다.
- 크롤러 엔드포인트는 운영 전 관리자 권한 보호가 필요하다.

## 4. 현재 검증 완료 범위

- 회원가입/로그인/JWT 인증
- 공지사항 크롤링, 저장, 목록/상세/검색 조회
- 식단 이미지 1건 크롤링, 날짜별 저장 및 조회
- 시간표 생성/목록/상세 조회
- 개인 일정 생성/조회/삭제
- 시간표 강의 추가 API의 존재하지 않는 강의 404 처리
