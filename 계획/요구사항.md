# KNU Campus Life — 요구사항 정의서

> 강남대학교 졸업작품 | 2026 | 1인 개발

---

## 1. 프로젝트 개요

강남대학교 재학생을 위한 통합 모바일 앱으로, 공지사항, 시간표, 학식, 캠퍼스 맵, AI 챗봇, 졸업 요건 체커 기능을 하나의 앱에서 제공한다.

---

## 2. 사용자 요구사항

### 2.1 인증

- 회원가입: 이메일, 비밀번호, 이름으로 가입할 수 있다.
- 로그인: 이메일과 비밀번호로 로그인하면 JWT 토큰을 발급받는다.
- 토큰 갱신: refresh_token으로 만료된 access_token을 갱신할 수 있다.
- 비밀번호는 bcrypt로 해싱하여 저장한다.

### 2.2 공지사항

- 강남대학교 홈페이지 공지사항을 자동으로 크롤링하여 DB에 저장한다.
- 전체 공지사항 목록을 조회할 수 있다.
- 카테고리(학사, 장학, 인사, 취업 등)로 필터링할 수 있다.
- 키워드로 공지사항을 검색할 수 있다.
- 공지사항 상세 내용을 조회할 수 있다.
- 공지사항을 수정하고 삭제할 수 있다.
- 중요 공지사항은 별도로 표시된다.

### 2.3 시간표

- 나만의 시간표를 생성, 조회, 삭제할 수 있다.
- 시간표에 강의를 추가, 수정, 삭제할 수 있다.
- 대표 시간표(is_main)를 설정할 수 있다.
- 시간표 마법사: 듣고 싶은 과목을 선택하면 충돌 없는 모든 조합을 계산하여 보여준다.
- 마음에 드는 조합을 선택하여 시간표로 저장할 수 있다.

### 2.4 AI 챗봇

- 학교 관련 질문(학칙, 공지사항 등)에 AI가 답변한다.
- RAG(Retrieval Augmented Generation) 방식으로 정확한 정보를 제공한다.
- 대화방을 생성, 삭제할 수 있다.
- 이전 대화 내용을 조회할 수 있다.
- AI 응답은 스트리밍 방식으로 제공된다.

### 2.5 캠퍼스 맵

- Google Maps 기반으로 캠퍼스 지도를 제공한다.
- 건물 마커와 건물 정보(이름, 층수, 설명)를 표시한다.
- 건물 간 경로 안내를 제공한다.

### 2.6 학식 메뉴

- 강남대학교 학식 메뉴를 자동으로 크롤링하여 DB에 저장한다.
- 날짜별 학식 메뉴를 조회할 수 있다.
- 코너별 메뉴와 가격, 칼로리를 확인할 수 있다.

### 2.7 졸업 요건 체커

- 학과별 졸업 요건 기준(전공 학점, 교양 학점, 총 학점, 졸업 종합 평가 유무)을 조회할 수 있다.
- 이수 완료한 과목을 추가, 삭제할 수 있다.
- 현재 이수 현황(전공/교양/총 학점)을 시각화하여 보여준다.
- 부족한 학점과 과목을 알려준다.

### 2.8 알림

- 새 공지사항 알림을 설정할 수 있다.
- 학식 오픈 알림을 설정할 수 있다.
- Firebase FCM을 통해 푸시 알림을 발송한다.

### 2.9 설정 & 마이페이지

- 프로필(이름, 학과, 학번, 학년)을 조회하고 수정할 수 있다.
- 알림 설정을 변경할 수 있다.
- 로그아웃할 수 있다.

## 3. 비기능 요구사항

### 3.1 성능

- 공지사항 크롤링은 1시간마다 자동으로 실행된다.
- API 응답 시간은 1초 이내를 목표로 한다.
- Redis 캐시를 활용하여 자주 조회되는 데이터의 응답 속도를 향상시킨다.

### 3.2 보안

- 비밀번호는 bcrypt 알고리즘으로 해싱하여 저장한다.
- JWT 토큰 방식으로 인증을 처리한다.
- access_token 유효기간: 60분
- refresh_token 유효기간: 14일
- 환경변수(.env)로 민감한 정보를 관리한다.

### 3.3 확장성

- Docker + Docker Compose로 개발 환경을 통일한다.
- AWS EC2 또는 GCP에 백엔드 서버를 배포한다.
- GitHub Actions로 CI/CD 자동 배포 파이프라인을 구축한다.

### 3.4 크로스플랫폼

- iOS와 Android 모두 지원한다.
- React Native + Expo로 단일 코드베이스로 개발한다.
