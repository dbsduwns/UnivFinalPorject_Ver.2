# KNU Campus Life 요구사항

## 1. 프로젝트 개요

강남대학교 학생을 위한 통합 앱으로, 공지사항, 식단, 강의/과목, 시간표, 개인 일정, 챗봇 기능을 제공한다. 백엔드는 FastAPI 기반 REST API로 구현하며, PostgreSQL에 데이터를 저장한다.

## 2. 기능 요구사항

### 2.1 사용자 인증

- 사용자는 이메일, 비밀번호, 이름으로 회원가입할 수 있다.
- 사용자는 이메일과 비밀번호로 로그인할 수 있다.
- 로그인 성공 시 access token과 refresh token을 발급한다.
- 사용자는 access token으로 현재 로그인한 본인 정보를 조회할 수 있다.
- 인증이 필요한 API에 토큰이 없거나 유효하지 않으면 401을 반환한다.

### 2.2 공지사항

- 시스템은 강남대학교 홈페이지의 공지사항을 크롤링해 DB에 저장할 수 있다.
- 사용자는 공지사항 목록을 조회할 수 있다.
- 사용자는 키워드로 공지사항을 검색할 수 있다.
- 사용자는 공지사항 상세 정보를 조회할 수 있다.
- 존재하지 않는 공지사항은 404를 반환한다.

### 2.3 식단

- 시스템은 강남대학교 식단 게시판에서 주간 식단표 이미지 URL을 크롤링할 수 있다.
- 식단표 제목의 날짜 범위를 분석해 날짜별 식단 이미지 데이터를 저장한다.
- 사용자는 날짜 기준으로 식단 이미지를 조회할 수 있다.
- 식단 데이터가 없는 날짜는 빈 배열을 반환한다.

### 2.4 강의/과목

- 시스템은 강남대학교 종합정보시스템의 개설강좌 리스트 HTML을 import할 수 있다.
- 사용자는 HTML 문자열 또는 HTML 파일 업로드로 강의 데이터를 저장할 수 있다.
- 시스템은 학수번호, 분반, 과목명, 교수명, 학점, 시수, 강의시간을 파싱한다.
- 파싱된 과목은 `subjects`, 강의 분반은 `courses`, 강의 시간은 `course_schedules`에 저장한다.
- 사용자는 강의 목록과 강의 상세 정보를 조회할 수 있다.
- 사용자는 과목명 키워드로 강의를 검색할 수 있다.

### 2.5 시간표

- 사용자는 본인 계정에 연결된 시간표를 생성할 수 있다.
- 사용자는 본인의 시간표 목록을 조회할 수 있다.
- 사용자는 특정 시간표의 상세 정보를 조회할 수 있다.
- 시간표 상세는 기본 정보, 추가된 강의 목록, 개인 일정 목록, 총 학점을 포함해야 한다.
- 사용자는 시간표에 실제 강의를 추가하거나 삭제할 수 있다.
- 사용자는 시간표에 개인 일정을 추가, 조회, 삭제할 수 있다.
- 존재하지 않거나 본인 소유가 아닌 시간표는 404를 반환한다.

### 2.6 챗봇

- 사용자는 채팅방을 생성할 수 있다.
- 사용자는 본인의 채팅방 목록을 조회할 수 있다.
- 사용자는 채팅방에 메시지를 전송할 수 있다.
- 시스템은 데모 provider를 통해 assistant 응답을 생성하고 DB에 저장한다.
- 사용자는 채팅방 메시지 목록을 조회할 수 있다.
- 향후 실제 LLM provider 또는 RAG provider로 교체 가능한 구조여야 한다.

## 3. 비기능 요구사항

- API는 Swagger 문서에서 테스트 가능해야 한다.
- DB 접근은 SQLAlchemy 세션을 통해 처리한다.
- 비밀번호는 평문 저장하지 않고 해시로 저장한다.
- JWT access token 기반 인증을 적용한다.
- 크롤러 및 import API는 운영 전 관리자 권한 보호가 필요하다.
- 종합정보시스템 강의시간의 교시-시간 매핑은 공식 교시표 확인 후 보정 가능해야 한다.

## 4. 검증 완료 범위

- 회원가입/로그인/JWT 인증
- 현재 사용자 조회
- 공지사항 크롤링 및 조회
- 식단 이미지 크롤링 및 날짜별 조회
- 강의 HTML 파일 업로드 import
- 강의 목록 조회
- 시간표 생성/목록/상세 조회
- 시간표에 실제 강의 추가
- 개인 일정 생성/조회/삭제
- 챗봇 데모 API, 채팅방 생성, 메시지 저장/조회
- 인증 실패 401, 미존재 리소스 404 응답

## 5. 향후 요구사항

- 시간표 강의 충돌 검사
- 개인 일정 충돌 검사
- 시간표 수정/삭제
- 대표 시간표 설정 변경
- 강의 검색 필터 확장: 학과, 학기, 교수명, 요일
- 실제 AI 챗봇 연동
- 관리자용 크롤링/데이터 import 화면
