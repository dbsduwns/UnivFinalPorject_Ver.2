# KNU Campus Life 요구사항

## 1. 프로젝트 개요

KNU Campus Life는 강남대학교 학생을 위한 통합 캠퍼스 앱이다. 공지사항, 식단, 셔틀 시간표, 강의/과목, 시간표, 개인 일정, AI 챗봇, 향후 졸업 관리 기능을 제공한다. 백엔드는 FastAPI 기반 REST API로 구현하고, 프론트엔드는 React Native Expo 기반 모바일 앱으로 구현한다.

## 2. 기능 요구사항

### 2.1 사용자 인증

- 사용자는 이메일, 비밀번호, 이름으로 회원가입할 수 있다.
- 사용자는 이메일과 비밀번호로 로그인할 수 있다.
- 로그인 성공 시 access token과 refresh token을 발급한다.
- 사용자는 access token으로 현재 로그인한 본인 정보를 조회할 수 있다.
- 현재 사용자 조회 응답에는 관리자 여부(`is_admin`)가 포함되어야 한다.
- 관리자는 일반 사용자와 같은 로그인 API를 사용하되, 로그인 후 권한과 UI가 다르게 동작해야 한다.
- Google 로그인은 앱에서 진입점을 제공하며, 백엔드 검증 로직은 운영 전 보완되어야 한다.
- 인증이 필요한 API에 토큰이 없거나 유효하지 않으면 401을 반환한다.
- 관리자 권한이 필요한 API에 일반 사용자가 접근하면 403을 반환한다.

### 2.2 관리자 권한

- 공지사항 크롤링, 수정, 삭제는 관리자만 수행할 수 있다.
- 식단 크롤링은 관리자만 수행할 수 있다.
- 강의 HTML import와 학과별 강의 크롤링은 관리자만 수행할 수 있다.
- 셔틀 시간표 크롤링은 관리자만 수행할 수 있다.
- 프론트엔드는 `is_admin` 값에 따라 일반 사용자 UI와 관리자 UI를 분기해야 한다.

### 2.3 공지사항

- 시스템은 강남대학교 홈페이지 공지사항을 크롤링해 DB에 저장할 수 있다.
- 시스템은 카테고리별 공지사항을 수집할 수 있다.
- 시스템은 이미 저장된 공지사항의 상세 재수집을 줄여야 한다.
- 사용자는 공지사항 목록을 조회할 수 있다.
- 사용자는 카테고리로 공지사항을 조회할 수 있다.
- 사용자는 키워드로 공지사항을 검색할 수 있다.
- 사용자는 공지사항 상세 정보를 조회할 수 있다.
- 관리자는 공지사항을 수정하거나 삭제할 수 있다.
- 존재하지 않는 공지사항은 404를 반환한다.
- 향후 사용자의 공지 읽음 상태를 기록하고 조회할 수 있어야 한다.

### 2.4 식단

- 시스템은 강남대학교 식단 게시판에서 주간 식단표 이미지 URL을 크롤링할 수 있다.
- 식단표 제목의 날짜 범위를 분석해 날짜별 식단 이미지 데이터를 저장한다.
- 사용자는 날짜 기준으로 식단 이미지를 조회할 수 있다.
- 식단 데이터가 없는 날짜는 빈 배열을 반환한다.

### 2.5 셔틀 시간표

- 시스템은 강남대학교 무료셔틀 안내 페이지에서 셔틀 시간표 다운로드 링크를 크롤링할 수 있다.
- 시스템은 다운로드 응답 헤더의 원본 파일명에서 학기 정보를 파싱할 수 있다.
- 시스템은 최신 셔틀 시간표를 조회할 수 있어야 한다.
- 사용자는 저장된 셔틀 시간표 목록을 조회할 수 있다.
- 사용자는 학기 기준으로 셔틀 시간표를 조회할 수 있다.
- 셔틀 시간표는 PDF 파일 다운로드 링크 형태로 제공한다.

### 2.6 강의/과목

- 시스템은 강남대학교 종합정보시스템의 개설강좌 리스트 HTML을 import할 수 있다.
- 관리자는 HTML 문자열 또는 HTML 파일 업로드로 강의 데이터를 저장할 수 있다.
- 관리자는 학과별 개설강좌 크롤링을 실행할 수 있다.
- 시스템은 학수번호, 분반, 과목명, 교수명, 학점, 시수, 강의시간을 파싱한다.
- 파싱된 과목은 `subjects`, 강의 분반은 `courses`, 강의 시간은 `course_schedules`에 저장한다.
- 사용자는 강의 목록과 강의 상세 정보를 조회할 수 있다.
- 사용자는 과목명, 학과, 교수명, 학기, 요일, 학점, 학수번호로 강의를 필터링할 수 있다.

### 2.7 시간표

- 사용자는 본인 계정에 연결된 시간표를 생성할 수 있다.
- 사용자는 본인의 시간표 목록을 조회할 수 있다.
- 사용자는 특정 시간표의 상세 정보를 조회할 수 있다.
- 시간표 상세는 기본 정보, 추가된 강의 목록, 개인 일정 목록, 총 학점을 포함해야 한다.
- 사용자는 시간표 이름, 학기, 대표 여부를 수정할 수 있다.
- 사용자는 시간표를 삭제할 수 있다.
- 사용자는 시간표에 실제 강의를 추가하거나 삭제할 수 있다.
- 사용자는 시간표에 개인 일정을 추가, 조회, 수정, 삭제할 수 있다.
- 시스템은 시간표에 강의를 추가할 때 기존 강의 및 개인 일정과의 시간 충돌을 검사해야 한다.
- 시스템은 개인 일정을 추가하거나 수정할 때 기존 강의 및 개인 일정과의 시간 충돌을 검사해야 한다.
- 대표 시간표는 선택 사항이다. 대표 시간표가 없으면 프론트엔드는 최신 생성 시간표를 기본으로 보여줄 수 있다.
- 존재하지 않거나 본인 소유가 아닌 시간표는 404를 반환한다.

### 2.8 AI 챗봇

- 사용자는 채팅방을 생성할 수 있다.
- 사용자는 본인의 채팅방 목록을 조회할 수 있다.
- 사용자는 채팅방에 메시지를 전송할 수 있다.
- 시스템은 RAG 기반 AI 응답을 생성하고 DB에 저장한다.
- 사용자는 채팅방 메시지 목록을 조회할 수 있다.
- 시스템은 공지사항, 셔틀 시간표, 학교 규정 데이터를 RAG 문서로 활용할 수 있어야 한다.
- AI 엔진이 준비되지 않은 경우 사용자에게 오류 메시지를 반환해야 한다.

### 2.9 졸업 관리 및 수강 설계

- 졸업 요건, 기이수 과목, 위저드 선택을 저장하기 위한 모델이 존재한다.
- 향후 학과별 졸업 요건 조회 API를 제공해야 한다.
- 향후 사용자의 기이수 과목을 등록하고 조회할 수 있어야 한다.
- 향후 졸업 진단 및 수강 설계 위저드 화면을 제공해야 한다.

### 2.10 프론트엔드

- 앱은 Expo Router 기반 파일 라우팅을 사용한다.
- 앱은 로그인, 회원가입, 인증 상태에 따른 리다이렉션을 제공한다.
- 앱은 access token과 refresh token을 SecureStore에 저장해야 한다.
- 앱은 API 요청 시 access token을 자동 첨부해야 한다.
- 앱은 인증 실패 시 토큰을 삭제하고 로그인 화면으로 이동해야 한다.
- 앱은 Google 로그인 버튼을 제공한다.
- 앱은 홈, 공지사항, 시간표, AI 채팅, 마이페이지 탭 구조를 제공한다.
- 공지사항, 식단, 셔틀, 시간표, AI 채팅 화면은 실제 API 연동을 통해 동작해야 한다.
- 관리자는 일반 사용자와 다른 관리자 화면 또는 관리자 기능 진입점을 볼 수 있어야 한다.

## 3. 비기능 요구사항

- API는 Swagger 문서에서 테스트 가능해야 한다.
- DB 접근은 SQLAlchemy 세션을 통해 처리한다.
- 비밀번호는 평문 저장하지 않고 해시로 저장한다.
- JWT access token 기반 인증을 적용한다.
- 관리자용 API는 서버에서 권한을 검증해야 한다.
- APScheduler를 사용하여 정기적 데이터 자동 크롤링을 수행한다.
- 크롤러는 학교 서버 부하를 고려해 중복 수집과 과도한 요청을 줄여야 한다.
- Alembic migration으로 DB 변경 이력을 관리한다.
- 운영 환경에서는 `create_all`보다 migration 중심으로 DB 스키마를 관리해야 한다.
- 프론트엔드는 React Native Expo 단일 코드베이스로 iOS/Android 대응을 목표로 한다.
- API 통신 시 로딩, 에러, 인증 만료 상태를 UI에서 처리해야 한다.

## 4. 검증 완료 범위

- 백엔드 서버 및 DB health check
- 이메일 회원가입/로그인/JWT 인증
- `/auth/me` 현재 사용자 조회 및 관리자 여부 응답
- 관리자 권한 dependency 적용
- 공지사항 크롤링 및 조회
- 공지사항 카테고리/키워드 필터
- 공지사항 수정/삭제 관리자 보호
- 식단 이미지 크롤링 및 날짜별 조회
- 식단 크롤링 관리자 보호
- 셔틀 시간표 크롤링 및 최신/목록/학기별 조회
- 셔틀 파일명 인코딩 처리 및 학기 파싱
- 강의 HTML 문자열/파일 import
- 학과별 강의 크롤링 import
- 강의 목록/상세 조회 및 필터 확장
- 시간표 생성/목록/상세/수정/삭제
- 시간표 강의 추가/삭제 및 충돌 검사
- 개인 일정 생성/조회/수정/삭제 및 충돌 검사
- 대표 시간표 설정
- 채팅방 생성, 메시지 저장/조회, RAG 기반 AI 응답
- APScheduler 기반 공지사항/식단/셔틀 정기 크롤링
- Alembic migration 관리
- 프론트엔드 Expo 프로젝트 초기화
- 프론트엔드 로그인/회원가입 화면
- 프론트엔드 Axios API 클라이언트, SecureStore 토큰 저장, Zustand auth store
- 프론트엔드 인증 상태 기반 리다이렉션
