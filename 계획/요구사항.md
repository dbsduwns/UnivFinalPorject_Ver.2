# KNU Campus Life 요구사항

## 1. 프로젝트 개요

강남대학교 학생을 위한 통합 앱으로, 공지사항, 식단, 강의/과목, 시간표, 개인 일정, 챗봇 기능을 제공한다. 백엔드는 FastAPI 기반 REST API로 구현하며, 프론트엔드는 React Native(Expo)를 사용하여 크로스 플랫폼 앱으로 구현한다.

## 2. 기능 요구사항

### 2.1 Backend (API)

#### 2.1.1 사용자 인증
- 사용자는 이메일, 비밀번호, 이름으로 회원가입할 수 있다.
- 사용자는 이메일과 비밀번호로 로그인할 수 있다.
- 로그인 성공 시 access token과 refresh token을 발급한다.
- 사용자는 access token으로 현재 로그인한 본인 정보를 조회할 수 있다.

#### 2.1.2 공지사항
- 강남대학교 홈페이지 공지사항 크롤링 및 저장.
- 목록 조회, 검색, 상세 조회, 읽음 상태 기록.

#### 2.1.3 식단
- 식단 게시판 이미지 크롤링 및 날짜별 저장.
- 날짜별 식단 이미지 조회.

#### 2.1.4 강의/과목 및 시간표
- 강의 데이터 import (HTML 파싱).
- 강의 목록/상세 조회 및 검색.
- 시간표 생성, 강의/개인 일정 추가 및 충돌 검사.

#### 2.1.5 챗봇 (AI)
- RAG 방식 기반 Gemini Pro 답변 생성.
- 채팅방 및 메시지 관리.

#### 2.1.6 졸업 관리 및 수강 설계 (Wizard)
- 학과별 졸업 요건 제공.
- 기이수 과목 관리 및 위저드 선택 보관.

### 2.2 Frontend (App)

#### 2.2.1 공통 및 인증
- iOS와 Android 플랫폼 최적화 UI/UX 제공.
- JWT 토큰 안전 관리 (SecureStore) 및 자동 로그인.

#### 2.2.2 대시보드 (홈)
- 오늘의 학식 요약, 다음 수업 시간/장소 표시, 최신 공지 카드.

#### 2.2.3 시간표
- 주간 시간표 시각화 및 인터랙티브 UI.
- 강의 상세 정보 팝업 및 개인 일정 표시.
- 검색 기반 강의 추가 flow.

#### 2.2.4 AI 캠퍼스 봇
- 메신저 스타일 채팅 인터페이스.
- 실시간 응답 대기 및 이전 내역 로드.

#### 2.2.5 수강 설계 (Wizard)
- 졸업 진단 시각화 및 단계별 과목 선택 UI.

## 3. 비기능 요구사항

- API는 Swagger 문서에서 테스트 가능해야 한다.
- DB 접근은 SQLAlchemy 세션을 통해 처리한다.
- JWT access token 기반 인증 적용.
- APScheduler를 사용하여 정기적 데이터 자동 크롤링.
- 프론트엔드는 React Native Expo를 사용하여 단일 코드베이스 대응.
- API 통신 시 로딩/에러 상태 UI 처리 철저.

## 4. 검증 완료 범위

- 백엔드 주요 API 및 크롤링 자동화 완료 (공지사항 V2, 학식, 셔틀).
- DB 마이그레이션(Alembic) 관리 체계 구축 및 적용.
- 졸업 요건, 건물 정보, 강의 데이터 모델링 및 Import 로직 완료.
- 사용자 인증(JWT) 및 `/auth/me` 연동 최적화 완료.
- 프론트엔드(Expo) 아키텍처 수립 및 API 연동 레이어(Axios, React Query, Zustand) 구축 완료.
- 프론트엔드-백엔드 간 인증 흐름(SecureStore 기반 토큰 관리) 검증 완료.

## 5. 향후 요구사항

- 실시간 푸시 알림 서비스.
- 관리자용 데이터 관리 웹 대시보드.
