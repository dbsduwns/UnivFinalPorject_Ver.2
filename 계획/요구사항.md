# KNU Campus Life 요구사항

> 기준일: 2026-11-11
>
> 현재 저장소의 FastAPI 백엔드, React Native Expo 앱, 관리자 웹과 테스트를 기준으로 정리한 요구사항이다. `완료`는 코드와 주요 테스트가 존재하는 기능, `운영 확인 필요`는 외부 서비스·실기기·배포 환경 검증이 필요한 기능, `예정`은 사용자 기능이 완성되지 않은 항목을 뜻한다.

## 1. 프로젝트 개요

KNU Campus Life는 강남대학교 학생을 위한 통합 캠퍼스 앱이다. 학생 인증을 기반으로 공지사항, 식단, 셔틀, 강의·시간표, AI 챗봇, 친구·시간표 공유, 1:1·단체 채팅, 커뮤니티, 통학 경로와 실시간 교통 정보를 제공한다.

- 모바일: React Native + Expo Router 기반 앱
- 백엔드: FastAPI REST API
- 운영 배포: Google Cloud Run, Supabase PostgreSQL, Qdrant Cloud, Cloudflare Workers AI
- 지도: Android `expo-maps` Google Maps 우선
- 외부 데이터: 강남대학교 공개 페이지, TMAP 주소 검색, Google Routes, 공공데이터포털(TAGO) 및 지역별 버스 API

## 2. 사용자 및 권한 정책

### 2.1 학생 인증과 계정

- 이메일·비밀번호 회원가입과 로그인을 제공한다. 학생 계정은 강남대학교 이메일 OTP 인증을 완료해야 정식 서비스 권한을 가진다.
- Google 로그인은 학생 인증 전 대기 상태로 처리하며, 인증 전 일반 기능 API 접근을 허용하지 않는다.
- 기존 이메일 계정과 Google 계정은 자동 연결하지 않는다. 사용자가 로그인한 뒤 별도 계정 연결을 수행한다.
- access token과 refresh token을 분리하고, refresh 세션의 `session_id`, 해시된 `jti`, 만료·폐기 상태·`token_version`을 검증한다. 정상 갱신 시 refresh token을 회전한다.
- 사용자는 프로필 수정, 비밀번호 변경·재설정, 회원 탈퇴를 수행할 수 있다.
- 생체 인증 자격 증명 등록·잠금·해제·삭제를 지원한다.
- 학교 포털 학번·비밀번호를 일반 사용자에게 수집하지 않는다. 크롤링에 필요한 서비스 계정은 관리자 영역과 Secret Manager로 제한한다.

### 2.2 권한

- 일반 사용자와 관리자는 같은 인증 체계를 사용한다.
- 사용자 정보의 `is_admin` 값에 따라 관리자 화면과 API 접근을 분리한다.
- 관리자만 공지·식단·셔틀·강의 수집 및 관리자용 사용자·커뮤니티 신고 관리 기능을 수행할 수 있다.
- 인증 실패는 401, 권한 부족은 403으로 반환한다.

## 4. 비기능 요구사항

- 비밀번호는 bcrypt로 해시 저장하고 JWT access·refresh 용도를 분리한다.
- refresh 세션 폐기·회전·재사용 탐지를 지원한다.
- PostgreSQL 스키마 변경은 Alembic으로 관리한다.
- 크롤러는 중복 수집을 방지하고 학교 서버 부하를 줄이도록 순차 실행한다.
- Cloud Run 환경변수와 Secret Manager의 실제 비밀값을 로그·소스에 노출하지 않는다.
- Qdrant·PostgreSQL은 컨테이너 로컬 파일시스템에 저장하지 않는다.
- 실시간 교통 부가기능이 실패해도 기본 경로 계산은 유지한다.
- 현재 위치는 지도·경로 계산에 필요한 범위에서만 사용하며 기본적으로 장기 저장하지 않는다.
- 통학 홈 경로 계산은 사용자별 60초 쿨다운을 적용한다.
- 모바일 앱은 로딩·빈 상태·네트워크 오류·권한 오류를 처리한다.

## 5. 현재 검증 범위

`backend/tests`에는 인증·비밀번호 검증, 알림 센터, 푸시·Presence, 친구·채팅, 커뮤니티 관리, 공지·학사일정·규정 크롤러, RAG 검색, 시간표 건물, 통학·실시간 교통, Cloud Run Job, 앱 업데이트 테스트가 포함되어 있다. 프론트엔드는 Expo lint·TypeScript 검사와 Android 실기기 검증을 배포 전 수행한다.

## 6. 후속 개발 우선순위

1. Android 실기기·운영 환경에서 Google 지도와 지역별 실시간 버스 API 검증
2. 공지 읽음 상태와 졸업 요건·기이수 과목·진단 위저드 완성
3. 메시지 방장·초대·내보내기 권한 및 운영 정책 확정
4. 푸시 Receipt 처리와 만료 토큰 정리 자동화
5. 셔틀 PDF 영구 저장소 도입

## 7. 배포 기준

- API: Google Cloud Run
- 관계형 데이터: Supabase PostgreSQL
- 벡터 데이터: Qdrant Cloud
- AI: Cloudflare Workers AI(Qwen 채팅, BGE-M3 임베딩)
- 배치: Cloud Run Job + Cloud Scheduler
- 비밀값: Google Secret Manager
- 모바일: Expo/EAS Android 개발·배포 빌드
