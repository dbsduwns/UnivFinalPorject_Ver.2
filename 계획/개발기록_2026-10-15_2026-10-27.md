## 기간 요약

이 기간에는 학사 일정·커뮤니티 관리·통학 지도/실시간 교통·친구 초대·AI 챗봇/RAG·학식 OCR·공지 이미지·크롤러·푸시·1:1/단체 채팅을 집중적으로 개발했다. 특히 통학 기능은 경로 계산에서 실시간 버스·지하철 추적까지 확장됐고, 채팅은 단체방과 사용자별 알림 제어까지 구현됐다.

| 기능 영역 | 완료·개선 내용 |
| --- | --- |
| 일정/기본 UI | 일정 화면과 스크롤·지도 유틸 정리 |
| 커뮤니티/공지 | 관리자 게시물·댓글 신고 관리, 공지 관리자 및 이미지 표시 보완 |
| 통학/지도 | Google Maps 기반 경로, 셔틀 좌표, 실시간 버스·지하철 도착/위치 추적 |
| 친구/계정 | 친구 초대 링크, 친구 관리, 로그인 검증, 전체 데이터 삭제형 회원 탈퇴 |
| AI 챗봇 | 사전 초기화, 스트리밍, 검색 필터·평가, 메뉴/시간표 컨텍스트 연결 |
| 메뉴/크롤링 | 학식 이미지 OCR, RAG 재색인, 공지·셔틀·식단 변경 감지 |
| 푸시/채팅 | 크롤링 푸시, 테스트 푸시, 1:1 메시지 푸시, Presence, 단체 채팅 UI/설정 |

### 10월 27일 — Presence, 단체 채팅, 채팅 알림 제어

#### Presence 기반 푸시 억제

- 사용자별 앱/대화방 상태를 저장하는 `user_presences` 모델을 추가했다.
  - `user_id`, `active_room_id`, `is_app_foreground`, `last_seen_at`
- `PUT /api/presence`로 로그인 사용자의 상태를 생성·갱신한다.
- 앱 전역 레이아웃에서 전경/백그라운드와 45초 heartbeat를 동기화한다.
- 채팅방 진입·이탈 시 활성 방 ID를 갱신한다.
- 수신자가 최근 60초 이내에 동일 방을 전경에서 보고 있으면 서버가 1:1 푸시 전송을 생략한다.
- 프론트 알림 핸들러도 현재 사용자 ID·방 ID를 확인해 경합으로 도착한 동일 방 푸시의 배너·소리·목록·배지를 숨긴다.

#### 채팅방 설정과 단체 채팅

- `room_participants.is_muted`를 추가해 사용자별·대화방별 알림 차단 상태를 저장한다.
- 알림을 차단한 1:1 대화방은 메시지 푸시 대상에서 제외된다.
- 단체방 이름 변경과 방별 알림 설정 API를 추가했다.
- 새 채팅 모달에서 친구 1명 선택 시 1:1, 친구 2명 이상 선택 시 단체 채팅을 만든다.
- 채팅방 길게 누르기 메뉴에서 이름 변경, 알림 켜기/차단, 방 나가기/삭제를 제공한다.
- 단체방 수신 메시지 왼쪽에 발신자 닉네임 첫 글자 프로필과 닉네임을 표시한다.
- 푸시를 누르면 해당 `roomId`의 채팅방으로 바로 이동한다.

관련 커밋: `5ed0d9a`, `23b3fe7`

## 주요 API 및 데이터 구조

| 요청 | 설명 |
| --- | --- |
| `PUT /api/presence` | 현재 사용자의 활성 방·앱 전경 상태 upsert |
| `POST /api/chat/rooms` | 1:1 또는 단체 채팅방 생성 |
| `PATCH /api/chat/rooms/{room_id}` | 단체 채팅방 이름 변경 |
| `PATCH /api/chat/rooms/{room_id}/notification` | 현재 사용자의 방별 알림 차단 여부 변경 |
| `DELETE /api/chat/rooms/{room_id}` | 현재 사용자의 채팅방 나가기 |
| `POST /auth/notification-test` | 현재 사용자 기기로만 테스트 푸시 요청 |

Presence 요청 예시:

```json
{
  "active_room_id": 123,
  "is_app_foreground": true
}
```

메시지 푸시 데이터:

```json
{
  "type": "direct_message",
  "room_id": 123,
  "sender_id": 10,
  "recipient_id": 20
}
```

### Cloud Run / Scheduler

- API 서비스와 크롤러 Job은 별도 이미지·별도 배포 대상이다.
- Scheduler는 Cloud Run Job을 실행하도록 설정한다.
- 크롤러 Job 명령은 `python scripts/run_daily_crawlers.py`를 사용한다.

### Expo / Android FCM

- Android 원격 푸시는 Expo Go가 아닌 개발자 빌드 또는 배포 빌드에서 확인한다.
- Expo/EAS Android Service Credentials에 Firebase FCM V1 서비스 계정 키를 등록한다.
- `google-services.json`의 Firebase 프로젝트와 FCM 자격 증명 프로젝트가 일치해야 한다.
