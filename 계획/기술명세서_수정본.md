# KNU Campus Life 기술명세서 수정본

## 1. 백엔드 기술 스택

- FastAPI 기반 REST API 서버
- SQLAlchemy ORM
- PostgreSQL
- Alembic 마이그레이션
- JWT 인증
- Playwright 기반 공지사항/식단 크롤러

## 2. 구현 완료 API

### 2.1 인증

- `POST /auth/signup`: 회원가입
- `POST /auth/login`: 로그인 및 access/refresh token 발급
- `GET /auth/me`: Bearer access token 기반 현재 사용자 조회

### 2.2 공지사항

- `POST /api/notices/crawl?max_items=3`: 공지사항 크롤링 및 DB 저장
- `GET /api/notices/`: 공지사항 목록 조회
- `GET /api/notices/?keyword={keyword}`: 키워드 검색
- `GET /api/notices/{notice_id}`: 공지사항 상세 조회
- `PUT /api/notices/{notice_id}`: 공지사항 수정
- `DELETE /api/notices/{notice_id}`: 공지사항 삭제

### 2.3 식단

- `POST /api/daily-menus/crawl?max_items=1`: 식단 이미지 1건 크롤링 및 날짜별 DB 저장
- `GET /api/daily-menus/?date=YYYY-MM-DD`: 날짜별 식단 이미지 조회

### 2.4 시간표

- `POST /api/timetables/`: 내 시간표 생성
- `GET /api/timetables/`: 내 시간표 목록 조회
- `GET /api/timetables/{timetable_id}`: 내 시간표 상세 조회
- `POST /api/timetables/{timetable_id}/courses`: 시간표에 강의 추가
- `DELETE /api/timetables/{timetable_id}/courses/{course_id}`: 시간표에서 강의 삭제
- `POST /api/timetables/{timetable_id}/custom-schedules`: 개인 일정 추가
- `GET /api/timetables/{timetable_id}/custom-schedules`: 개인 일정 목록 조회
- `DELETE /api/timetables/{timetable_id}/custom-schedules/{schedule_id}`: 개인 일정 삭제

## 4. 검증 결과

- `/health`, `/health/db` 정상 응답
- 회원가입, 로그인, JWT 인증 정상 동작
- 공지사항 크롤링 후 목록/상세/검색 API 정상 동작
- 식단 이미지 1건 크롤링 후 날짜 범위별 조회 정상 동작
- 시간표 생성/목록/상세 조회 정상 동작
- 개인 일정 생성/조회/삭제 정상 동작
- 인증 누락 요청은 `401 Not authenticated` 반환
- 존재하지 않는 리소스는 `404` 반환

## 5. 개발 참고

- `POST /api/notices/crawl`, `POST /api/daily-menus/crawl`은 개발/관리용 엔드포인트이므로 운영 전 관리자 인증 적용이 필요하다.
- 개발 단계에서는 누락 테이블 생성을 위해 FastAPI startup에서 `Base.metadata.create_all(bind=engin)`을 실행한다. 운영 단계에서는 Alembic migration 중심으로 전환한다.
